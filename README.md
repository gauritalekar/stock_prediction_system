# 📈 Intelligent Risk-Aware Stock Market Prediction System

An AI-powered stock market prediction application built with **Python, Streamlit, TensorFlow (LSTM), and Yahoo Finance**. The system analyses historical stock prices, predicts the next day's closing price, and generates **Buy, Hold, or Sell** trading signals using technical indicators.

## 🚀 Features

* Real-time stock data using Yahoo Finance
* LSTM-based stock price prediction
* Technical indicators (MA20, RSI, MACD)
* Buy / Hold / Sell signal generation
* Portfolio backtesting
* Interactive Streamlit dashboard
* Prediction accuracy using RMSE
* Actual vs Predicted price visualization

## 🛠️ Technologies Used

* Python
* Streamlit
* TensorFlow / Keras
* Scikit-learn
* Pandas & NumPy
* Matplotlib
* yFinance

## ▶️ Run the Project

```bash
pip install streamlit tensorflow yfinance pandas numpy matplotlib scikit-learn
streamlit run stock_prediction.py
```
